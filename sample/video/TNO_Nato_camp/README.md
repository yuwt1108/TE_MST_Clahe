# TNO NATO Camp 双光测试片段

可见光和热红外各 32 帧，尺寸均为 360 × 270。同名 BMP 是一对，编号为 1800 到 1831。

两段 MP4 由原始帧按编号以 10 fps 编码，时长各为 3.2 秒。10 fps 是预览播放速率。逐帧融合测试可直接读取对应的 BMP。

来源：Alexander Toet, TNO, Soesterberg, The Netherlands. [TNO Image Fusion Dataset](https://doi.org/10.6084/m9.figshare.1008029)。原始帧取自 [数据集镜像](https://github.com/yanyanchun/TNO_Image_Fusion_Dataset/tree/HEAD/Nato_camp_sequence)。
