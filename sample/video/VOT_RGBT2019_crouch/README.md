# VOT-RGBT2019 · crouch

可见光与热红外各 1041 帧，630 × 460，数据集标注帧率 30 fps。两段预览 MP4 各 34.7 秒。

原始 JPEG 分别存于 Visible 和 Infrared，两路统一使用 00001.jpg 至 01041.jpg 的文件名，同名即为一对。MP4 由同一组帧编码，逐帧测试可直接读取原始 JPEG。

来源：[VOT2019 官方数据集](https://www.votchallenge.net/vot2019/dataset.html) · [数据集元数据](https://data.votchallenge.net/vot2019/rgbtir/meta/description.json)，序列名 crouch。
